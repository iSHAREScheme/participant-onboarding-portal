# Release process

This repo publishes versioned container images and GitHub Releases from tags.

## Versioning

- Use SemVer tags: `vX.Y.Z`.
- For prereleases, use `vX.Y.Z-rc.N` or similar.

## Steps

1. Update `CHANGELOG.md` (move entries from Unreleased to a version section).
2. Ensure CI is green on `main`.
3. Create and push a tag:
   - `git tag -a vX.Y.Z -m "Release vX.Y.Z"`
   - `git push origin main --tags`

## What happens on tag

- `.github/workflows/build-images.yml` builds and pushes images:
  - `ghcr.io/<owner>/onboarding-portal-backend:<tag>`
  - `ghcr.io/<owner>/onboarding-portal-frontend:<tag>`
  - `ghcr.io/<owner>/onboarding-portal-keycloak:<tag>`
- `.github/workflows/build-images.yml` creates a GitHub Release with autogenerated notes
  after the image builds succeed.

## Using a release

Set `GHCR_OWNER` and `IMAGE_TAG` in `.env`, then run:

```sh
docker compose -f docker-compose.prod.yml up -d
```
