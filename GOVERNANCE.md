# Governance

The iSHARE Participant Onboarding Portal is maintained by the iSHARE Foundation.

## Maintainers
- The iSHARE Foundation maintains the project and has final decision authority.

## Decision-making
- Day-to-day decisions are made by maintainers based on project goals and user impact.
- Substantial changes should be discussed in an Issue before a PR is merged.

## Contributions
We welcome contributions via GitHub pull requests. See `CONTRIBUTING.md` for
details.
