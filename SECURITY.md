# Security Policy

## Reporting a Vulnerability
Please report security issues via GitHub Security Advisories:
https://github.com/iSHAREScheme/participant-onboarding-portal/security/advisories/new

If you cannot use GitHub, email `support@ishare.eu`.

Please do not open public issues for security vulnerabilities.

## Supported Versions
We provide security updates for the latest released version and the `main`
branch. Older versions may not receive fixes.

## Response Targets
We aim to acknowledge reports within 5 business days and provide a remediation
plan or patch as soon as feasible.
