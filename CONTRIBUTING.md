# Contributing

Thanks for your interest in contributing to the iSHARE Participant Onboarding Portal!

## Getting started
- Fork the repo and create a feature branch.
- See `README.md` for local setup instructions.
- Run relevant checks before opening a PR:
  - Backend: `cd backend && go test ./...`
  - Frontend: `cd frontend && yarn install && yarn lint`

## Pull requests
- Keep changes focused and easy to review.
- Update docs and configuration examples when behavior changes.
- Add or update tests where applicable.
- Include a clear description of the problem and solution.

## Code of conduct
By participating, you agree to the Code of Conduct in `CODE_OF_CONDUCT.md`.
