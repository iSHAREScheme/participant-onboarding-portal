# Support

We provide community support on a best-effort basis.

## Where to get help
- **Bug reports**: open a GitHub Issue with reproduction steps and logs.
- **Feature requests**: open a GitHub Issue with the problem and desired outcome.
- **Questions**: use GitHub Discussions if enabled; otherwise open an Issue.

## What to include
- Version or image tag
- Deployment type (local Docker Compose, production, etc.)
- Steps to reproduce and expected vs. actual behavior
